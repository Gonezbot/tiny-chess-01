TinyPeSTO-Py313 is a compact chess engine in 4 KB of Python: tapered PeSTO evaluation, alpha-beta search with transposition table and quiescence, fixed node budget, fully deterministic. Evaluation weights and Piece-Square Tables are based on "PeSTO's Evaluation Function" by Ronald Friederich (Chess Programming Wiki, CC BY-SA 3.0). MIT licensed.

## Run it

```sh
MAKEFUN_ENV_URL=http://localhost:8080 python3 main.py
```
